# QA Automation Project

## Overview

This project demonstrates practical QA automation testing using Playwright, API testing, SQL database validation, and Git/GitHub.

## Testing Areas

- Web UI automation with Playwright
- Page Object Model (POM)
- Positive and negative login testing
- API testing with Postman
- SQL database testing
- Git version control
- GitHub repository management

## Web Automation

The Playwright tests cover:

- Successful login
- Invalid password
- Empty username
- Empty password
- Empty username and password

## Tools & Technologies

- Playwright
- JavaScript
- Postman
- SQL
- SQLite
- Git
- GitHub
- VS Code
